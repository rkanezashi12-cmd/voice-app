# テスト用の商談の台本（3〜4分）

録音のテスト（対面録音・ボット）で、要約だけでなく構造化項目（課題・ニーズ・予算・決裁者・競合・次のアクション・次回期限）
まで確かめるための台本。2人で読み上げる。会社名・人名は架空。
「来週の金曜日、10月9日」は試す日に合わせて読み替える（次回期限の確認に使う）。

中子・抜き勾配・湯口・鋳肌・マッチプレートなどの専門用語を入れてある。用語辞書の効き目を見るときにも使う（下の「用語辞書」）。

## 台本

| 話す人 | せりふ |
|---|---|
| 営業 | 本日はお時間をいただきありがとうございます。マルサン木型の佐藤です。 |
| お客様 | サンプル鋳造の田中です。よろしくお願いします。 |
| 営業 | さっそくですが、いま木型でお困りのことを教えていただけますか。 |
| お客様 | 一番は納期です。今お願いしているところだと、木型ができるまで6週間かかっていて、新製品の試作が遅れています。 |
| 営業 | 6週間ですか。それは長いですね。 |
| お客様 | それと、量産で何度も使っていると木型がすり減って、鋳物の寸法がばらつくんです。特に中子の部分と、抜き勾配のところが崩れやすくて。 |
| 営業 | なるほど。摩耗で寸法が安定しないということですね。 |
| お客様 | ええ。なので、納期は3週間くらいまで縮めたいのと、量産用は樹脂型に切り替えて長持ちさせたいと思っています。 |
| 営業 | 弊社では3D CAD のデータから直接 NC 加工で木型を作れますので、3週間は十分狙えます。樹脂型やマッチプレートにも対応しています。 |
| お客様 | CAD データから作ってもらえるのは助かります。図面を起こす手間が省けるので。 |
| 営業 | ご予算はどのくらいでお考えでしょうか。 |
| お客様 | 今期は、木型全体で300万円くらいを見ています。 |
| 営業 | ありがとうございます。最終的なご判断はどなたがされますか。 |
| お客様 | 金額が大きいので、最後は工場長の山本が決めます。私が見積もりを比べて、山本に上げる形です。 |
| 営業 | 承知しました。ほかにもご検討されているところはありますか。 |
| お客様 | 地元の木型屋さん2社にも声をかけています。あと、3Dプリンタで砂型を直接作る方法も少し調べています。 |
| 営業 | 3Dプリンタの砂型は、試作の数が少ないときには向いていますが、量産の数が多いなら樹脂型のほうが1個あたりは安くなります。その比較も見積もりに付けますね。 |
| お客様 | それはありがたいです。 |
| 営業 | では次の進め方ですが、田中様から対象の部品の CAD データと図面をお送りいただけますか。 |
| お客様 | はい、今週中に送ります。 |
| 営業 | いただいたら、弊社で見積もりと納期の案を作って、来週の金曜日、10月9日までにお送りします。 |
| お客様 | わかりました。湯口の位置も相談したいので、見積もりのときにあわせて提案をお願いします。 |
| 営業 | 承知しました。湯口の位置と、鋳肌をきれいにするための仕上げもあわせてご提案します。本日はありがとうございました。 |
| お客様 | ありがとうございました。 |

## 期待する結果（CRM の商談記録）

| 項目 | 入っていてほしい内容 |
|---|---|
| 要約 | 納期短縮と木型の摩耗の相談。CAD データから製作し、見積もりと納期案を出すこと |
| 課題 | 木型の納期が6週間で試作が遅れている／摩耗で鋳物の寸法がばらつく（中子・抜き勾配） |
| ニーズ | 納期を3週間に短縮／量産用を樹脂型に切り替え／CAD データから製作 |
| 予算 | 今期、木型全体で300万円程度 |
| 決裁者 | 工場長の山本さん |
| 競合 | 地元の木型屋2社／3Dプリンタによる砂型 |
| 次のアクション | お客様：CAD データと図面を送る（今週中）／営業：見積もりと納期案を送る（10月9日まで）、湯口の位置と仕上げを提案 |
| 次回期限 | 次のアクションの期限のうち一番早い日（「今週中」に日付が付けば今週の金曜日、付かなければ10月9日） |
| 文字起こし全文 | 話者A／B（対面録音）か、参加者名（ボット）で発言が並ぶ。専門用語の表記を確かめる |

違いがあれば、その項目と文字起こし全文の該当部分（画面のスクリーンショットでよい）を送る。プロンプト（`prompts/`）を直す材料にする。

## 用語辞書（任意）
