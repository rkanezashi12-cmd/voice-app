# 本番運用に切り替える（商談記録の名前の【TEST】を外す）

テスト中は、バックエンドが作る商談記録（録音アプリで作る記録・デスクトップ方式の記録）の名前の先頭に【TEST】が付く
（`CRM_TEST_RECORDS=true`）。本番運用では付けないようにし、テストで作った記録を CRM の画面で消す。
CRM の画面で作る商談記録（録音用URL・ボット）の名前は、もともと変えない（入れたとおり）。

- 変えるのは Cloud Run の環境変数 `CRM_TEST_RECORDS` だけ。`DRY_RUN`（CRM に書き込むか）・クライアント設定・コードは変えない
- テストの記録を消すのは CRM の画面で行う（バックエンドには削除の処理を作らない決まり。CLAUDE.md のルール6）
- いつでも元に戻せる（`bash scripts/go_live.sh --test`）

切り替える時期：お客様との打合せ（営業担当者のアカウントでのログイン）と、長い録音のテストが終わったあと。

## 1. テストの記録を消す（CRM の画面、10分）

1. CRM で「商談記録」を開き、一覧の左の「フィールドで絞り込み」で「商談記録名」にチェックを入れ、
   「次の値で始まる」に `【TEST】` を入れて「適用」する
2. 一覧の見出しのチェックで全件を選び、「削除」する（削除した記録はしばらく「ごみ箱」から元に戻せる）
3. 【TEST】が付いていないテストの記録も消す（CRM の画面で手で作ったもの。ボットのテストで作った商談記録など）。
   名前・作成日で探して、1件ずつ確かめてから消す

- 消すのは**テストで作った商談記録だけ**。用語辞書に登録した言葉（中子・抜き勾配など）は本番でも使うので残す
- 先方担当者（連絡先）の紐づけは、商談記録と一緒に消える想定（連絡先そのものは消えない）
- 録音・音声は、文字起こしのあとに消しているので、残っていない

## 2. 【TEST】を外す（Cloud Shell、3分）

```bash
cd ~/voice-app && git pull && bash scripts/go_live.sh
```

今の設定（`DRY_RUN` と `CRM_TEST_RECORDS`）が表示されるので、`DRY_RUN=false` であることを確かめて `yes`。
数十秒で新しい版に切り替わる（コードはそのまま。デプロイし直さなくてよい）。

`DRY_RUN=true のままです` と出たら、CRM に書き込まない設定のまま（テスト用）。本番運用では `DRY_RUN=false` にする
（2026-10 時点のマルサン木型の設定は `false`）。

## 3. 確かめる

録音アプリで1件録り、できた商談記録の名前の先頭に【TEST】が付いていないことを確かめる。

## 元に戻す

```bash
cd ~/voice-app && bash scripts/go_live.sh --test
```
