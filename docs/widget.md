# 商談日報ウィジェット（PC の CRM の商談記録の画面）

PC で CRM の商談記録を開いたとき、関連リストの欄に日報と文字起こし全文を見やすく出す Zoho CRM のウィジェット。
コードは `widgets/meeting-report/`、ZIP は `scripts/build_widget.py` で作る。

| 欄 | 出すもの |
|---|---|
| 見出し | 商談記録名・状態（色付き）・開始日時・商談形態・取得方法・取引先（押すと取引先を開く）・先方担当者・担当・分類 |
| 日報 | 要約（幅いっぱい）・課題・ニーズ・予算・決裁者・競合・次のアクション・次回期限。空の項目は出さない（録音アプリの日報と同じ順） |
| 説明 | 失敗したときはエラー内容、処理中・録音待ちのときはその旨（「再読み込み」で読み直す） |
| 文字起こし全文 | 話者ごとに色分けして出す（2つの項目に分かれた分もつなぐ）。言葉で検索し、当たった数と前後への移動（Enter で次） |

- **読むだけ。** CRM には何も書かない。開いた人の CRM の権限で、開いている商談記録1件だけを読む（ウィジェットの SDK）
- 置くのは新しく作った「商談記録」の画面だけ（取引先・連絡先などの既存の画面は変えない）
- バックエンド（Cloud Run）は使わない。ZIP を Zoho に登録する（ホスティング：Zoho。2026-10-06 にお客様の CRM で表示を確認）
- 項目の API 名は `app/field_map.py` の既定値から ZIP に入れる（ウィジェットのコードに直書きしない）

## 1. ZIP を作る（Cloud Shell、2分）

```bash
cd ~/voice-app && git pull && python3 scripts/build_widget.py
cloudshell download dist/meeting-report-widget.zip
```

- Zoho のウィジェット SDK（`live.zwidgets.com`）を取って ZIP に入れる（CDN から読ませると止まることがあるため）
- 2行目でパソコンに保存する（Cloud Shell の「︙」→「ダウンロード」で `voice-app/dist/meeting-report-widget.zip` を選んでもよい）
- ZIP は解凍・再圧縮しない（形が変わると Zoho に断られる）

## 2. CRM に登録する（PC のブラウザ、5分）

1. CRM の 設定 → 開発者スペース → ウィジェット →「ウィジェットを作成」
2. 次のとおり入れて保存する
   - 名前：`商談日報`
   - 種類：**関連リスト**（後から変えられない）
   - ホスティング：Zoho
   - ファイル：手順1の `meeting-report-widget.zip`
   - インデックスページ：**`/index.html`**（`/app/` は付けない。Zoho は ZIP の中の `app` フォルダーを一番上の階層として置く）
3. 商談記録を1件開き、左の「関連リスト」の下の「関連リストを追加する」から、ウィジェットの「商談日報」を選んで追加する
4. 「Page Not Found」が出たら、インデックスページを確かめて直し、**ブラウザのキャッシュを消して**開き直す
   （2026-10-06 は、インデックスページを直したあと、キャッシュを消したら出た）

## 3. 確かめる

- 処理が終わった商談記録を開き、関連リスト「商談日報」に日報と文字起こし全文が出る
- 検索欄に「中子」などを入れ、当たったところに色が付き、件数が出る
- 取引先の名前を押すと、取引先の画面が開く

## ウィジェットを直したとき

1. 手順1で ZIP を作り直す
2. 設定 → 開発者スペース → ウィジェット →「商談日報」を開き、新しい ZIP をアップロードして保存する
3. 表示が変わらなければ、ブラウザのキャッシュを消して開き直す

## うまくいかないとき

| 症状 | 原因と対処 |
|---|---|
| 「Page Not Found」（Zoho の困った顔の画面） | インデックスページの誤り。`/index.html` にして保存し、ブラウザのキャッシュを消して開き直す。Zoho がファイルを置いた場所は、ウィジェットの編集画面の「ベースURL」の後ろに `/main.js` を付けて開くと確かめられる（プログラムの文字が出れば、そこにある） |
| 「読み込み中…」のまま変わらない | SDK が読めていない。`python3 scripts/build_widget.py` がエラー無く終わったかを見て、ZIP を作り直す |
| 「Please upload a proper file」 | ZIP の形が違う。手順1で作った ZIP を、解凍・再圧縮せずにそのまま上げる |
| 「このウィジェットは「商談記録」の画面で使います」 | 商談記録以外の画面に置いた。商談記録の画面に置き直す |
| 「CRM から読めませんでした（NO_PERMISSION …）」 | 開いた人に、その商談記録を見る権限が無い |
| 枠が小さく、下が切れる | 関連リストの高さ合わせが効いていない（docs/unverified-apis.md の W4）。文字起こしの欄は枠の中でスクロールできる |
